# SONY-ZV-E-10-Settings

Sony ZV-E10 streaming configuration, diagnostics, and setup checklist for use with
Elgato Cam Link 4K and OBS Studio (2-24 hour continuous streams).

## Contents
- `CONTEXT.md` — Full diagnostic context block (hardware, issues, root causes, master config).
- `SETUP_CHECKLIST.md` — Step-by-step setup checklist to tick off.
- `CHANGELOG.md` — Version history and completed setup steps.
- `VERSION.txt` — Current version.
- `Image Files/` — Reference images (target look + problem samples + hardware photos).
- `Text Files/`, `Settings Files/`, `Programming Files/`, `Audio Files/`, `Video Files/`,
  `Document Files/`, `Archive Files/`, `Database Files/`, `OBS & Stream Files/` —
  file-format organized storage.

## Quick start
1. Read `CONTEXT.md` for baseline reality of the rig.
2. Work through `SETUP_CHECKLIST.md` top to bottom, ticking steps.
3. After each completed setup, bump `VERSION.txt` and append to `CHANGELOG.md`.
